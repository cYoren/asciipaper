asciipaper

Your desktop, drawn in characters.

Live wallpapers that move with your mouse. One click turns them into LEGO, pixel art, CRT glass, Game Boy or Matrix code, and any picture or video you love becomes one too. Free and open source.

⬇ Windows Linux macOS ★ GitHub

This is running live in your browser. Move your pointer, then try a style:

38 styles, one click

Every wallpaper takes any style, then you fine-tune it live: 13 shapes, 21 character sets, 20 retro palettes, dithering, and effects you can stack: CRT curve, scanlines, bloom, RGB split, grain, glitch.

Make it yours

Port anything

Drop in a photo, a GIF, a video or a link to a post on X. asciipaper measures it and picks a great starting look.

Share a look in one line

Every look is a short code. Paste a friend's code and you get their exact style. Pictures you save carry their look inside.

Big text

Your name, a word, a quote: drawn in characters, rippling under your pointer, in any style.

Let AI design one

Ask Claude for "a slow teal aurora, CRT style". It writes the wallpaper, looks at each attempt, and sets the one you like.

Light on your PC

A tiny native engine draws on the GPU at under 1% of a CPU core, and pauses behind fullscreen windows.

Write your own

A wallpaper is one GLSL function. Save the file and it updates on your desktop as you type.

Get it

Windows 10 and 11

Download the installer from Releases and run it. No admin rights needed. It lives in the tray and starts with Windows.

Linux

Hyprland, KDE Plasma, Sway, niri, COSMIC and other Wayland desktops.

macOS

Export any wallpaper as a ZIP (from Windows or Linux, or one a friend shares), unzip, and open index.html in the free Plash app.

git clone https://github.com/cYoren/asciipaper && cd asciipaper && ./install.sh   # Linux
claude mcp add --scope user asciipaper -- asciipaper mcp                            # let Claude design wallpapers
