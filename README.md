# ASCII Paper: the website

This repository holds **only the website** for [ASCII Paper](https://cyoren.github.io/asciipaper/),
served by GitHub Pages from `main`: the landing page, the live demos, and the pages the store
listings link to ([privacy](privacy.html), [community rules](community.html), [support](support.html)).

There is no app code, and there are no releases, here.

| You want | Go to |
|---|---|
| the app (Android, Chrome, Firefox live; Mac and Windows coming) | [cyoren.github.io/asciipaper](https://cyoren.github.io/asciipaper/) |
| the renderer, the specs, the WebGL runtime, builds to run yourself | **[cYoren/asciipaper-engine](https://github.com/cYoren/asciipaper-engine)** (open source, MIT) |

The site is plain static HTML with no build step: edit a file, commit to `main`, and Pages
publishes it. `demos/` is generated by `build-demos.sh`; do not hand-edit it.
