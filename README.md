# ASCII Paper: the website

This repository holds **only the website** for
[ASCII Paper](https://cyoren.github.io/asciipaper/), served by GitHub Pages from `main`:
the landing page, the live demos, and the pages the store listings link to
([privacy](privacy.html), [community rules](community.html), [support](support.html)).

There is no app code here.

| You want | Go to |
|---|---|
| the renderer, the specs, the WebGL runtime, builds for Windows / Linux / macOS / Android | **[cYoren/asciipaper-engine](https://github.com/cYoren/asciipaper-engine)** (open source, MIT) |
| the ASCII Paper app itself | [cyoren.github.io/asciipaper](https://cyoren.github.io/asciipaper/) |

The site is plain static HTML with no build step: edit a file, commit, and Pages publishes it.
`demos/` is generated by `build-demos.sh`; do not hand-edit it.
